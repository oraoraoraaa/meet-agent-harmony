# 参赛作品说明文档

本目录独立存放本次参赛文档，与 `docs/` 中的工程说明分开。

- `01-作品说明文档+为了看Miku演唱会特前来拿奖金.pdf`：提交文件。
- `report.tex`：主 LaTeX 源码；`introduction.tex`：限字介绍。
- `assets/`：本次模拟器截图，保留原始比例，不包括设置页或密钥。
- `evidence/`：本地验证记录，不纳入版本控制。
- `preview/`：本地逐页渲染，用于排版核验，不纳入版本控制。
- `build.sh`：使用 XeLaTeX 编译两遍，临时文件放在 `.build/`。

## 编译

本机已安装 TeX Live。进入本目录执行 `./build.sh`。需要 ctex、fontspec、TikZ 等宏包；字体优先使用 Windows 宋体 SimSun，否则使用 macOS 宋体 Songti SC。商业字体不打包分发。中文正文五号，单倍行距；标题二号加粗、作者与一级标题三号加粗、二级标题四号加粗。

采用本次用户给定的 100 字 / 1500 字限制；仓库旧模板中的 30 字 / 800 字限制已不适用。主体不超过 20 页。队名和作者已由用户确认沿用旧稿；未获得院校、专业或个人履历，未虚构填入。

仅 PDF 是正式提交文件；源码、预览及证据方便修改与核查。未附 HAP、密钥、签名证书、协议资质或商业字体。
