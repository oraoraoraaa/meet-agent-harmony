# Submission assets

This directory contains the contest submission, not application runtime resources.

- `01-作品说明文档-MeetAgent会合助手.tex`: editable LaTeX submission source.
- `01-作品说明文档-MeetAgent会合助手.pdf`: rendered submission.
- `figures/`: screenshots referenced by the submission.
- `submit_template.pdf`: original submission template.
- Root [申报材料.md](../申报材料.md): monthly incentive application text.

Keep these source/reference assets together. App resources live under `AppScope/resources/`
and `entry/src/main/resources/`. Project setup and current implementation status are in the
[root README](../README.md).
